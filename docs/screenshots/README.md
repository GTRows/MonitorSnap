# Screenshots

Captured from MonitorSnap v2.6.1 on Windows on November 2, 2026, at the default
1080 x 720 window size, using a separate temporary data directory.

- `presets.png`: a real saved three-monitor configuration and its global hotkey.
- `displays.png`: the current display layout and detected monitor properties.
- `settings.png`: theme, startup, behavior, and notification preferences.

The hardware layout has one primary display and two mirrored displays. These are
application captures, not mockups. No display configuration was applied to stage
the screenshots. Personal presets and settings were not used.

When replacing screenshots, capture the actual app, keep private data out of
view, and update the README alt text if the displayed configuration changes.
