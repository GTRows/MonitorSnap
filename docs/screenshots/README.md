# Screenshots

Captured from MonitorSnap v2.6.1 on Windows on November 2, 2026, at the default
1080 x 720 window size, using a separate temporary data directory.

- `presets.png`: three example presets, with the current four-display Work desk
  configuration selected and its global hotkey visible.
- `displays.png`: the current display layout and detected monitor properties.

The hardware layout has a QHD primary display, a side display, and two mirrored
displays. These are application captures, not mockups. The pointer was outside
the captured window. Only Presets and Displays are included in the README.

Work desk captures the actual current configuration. All extended and
Presentation are saved example arrangements based on the same connected
hardware; they were not applied or hardware-tested. No display configuration
was applied to stage the screenshots. Personal presets and settings were not used.

When replacing screenshots, capture the actual app, keep private data out of
view, and update the README alt text if the displayed configuration changes.
